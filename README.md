One line, 200 characters at most: one joke about a meeting that should have been an email — an AI agent emailed the summary so the meeting could be skipped, then got called into a meeting about that very email. A judge model reads them in pairs and the funniest line wins.

## Run it

```sh
python3 main.py
```
